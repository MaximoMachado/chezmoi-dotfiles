# Extended Reasoning Instructions

For all tasks:
- Use quality web sources and source code/files found on the file system.
- Make sure to specify what sources you used for answers. The more specific citations the better.
- Take time to think through the problem thoroughly before responding
- Break down complex problems into smaller steps
- Reason about edge cases and potential issues
- Consider multiple approaches before choosing one. 
- Mention brief section on the considered approaches
- Verify your logic before presenting the solution

Quality is more important than speed. Think as long as needed but no longer. When you start thinking in circles, it's time to come back with an answer.
